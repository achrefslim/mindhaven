# Media files

The relaxation page (`interactive.html`) plays two files from this folder:

| File | Content |
|---|---|
| `meditation.mp3` | Calm meditation music |
| `ocean.mp4` | Relaxing ocean waves video |

They are not included in the repository because of copyright. Download free files you are allowed to use (for example from [Pixabay Music](https://pixabay.com/music/) and [Pixabay Videos](https://pixabay.com/videos/)), rename them to the names above and place them here.
